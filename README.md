# bullet_on_needle
Implementing in Rust, C, and other languages, in order to provide program algorithms to apply numeric calculus methods. Developed on the context of a UFRN/DIMAp subject, in the 2026's second half <br>
<b>Disclaimer:</b> some folders here are dedicated to experimenting some implementing with programming langugages I'm learning (it'll be the case for most of the Rust implementing). So, if you'd like to see some programming really working for real, I highly recommend going to U1, U2 and U3 folders.

## Folders U_
"U" stands for unity: it's the common way college disciplines in Brazil divide the course, which's commonly in three parts. <br>
- <b>U1</b>: methods for finding zero for functions (like, $\dfrac{e^x-8\sec(x)}{\sqrt{\sin(x⁸-3x+7)}}-9x^{\frac{5}{4}}-6x=0$, and you'd like to obtain which value(s) of x are the solution for this and other hard stuff);
- <b>U2</b>: methods for solving Linear Systems, either with direct way or with iterecative way;
- <b>interpol</b>: it's also part of what my group made for the 2nd unity of the curse, but it's fully developed in C language and made in order to provide algorithms to solve interpolation problems given by our teacher (one of my favourite bands too haha could not name it differently).
